Quick Start

Four ways to start

Choose your preferred installation method and launch your first project in seconds.

npx (Recommended)

Zero install. Always runs the latest version.

npx setupkaro init my-app --template react-ts

Homebrew (macOS)

Native package management for Mac users.

brew tap setupkaro/brew
brew install setupkaro

Cargo (Rust Binary)

Blazing fast installation via Rust crate registry.

cargo install setupkaro

Standalone Binary

Direct shell installer for Linux, macOS, & Windows.

curl -fsSL https://setupkaro.in/install.sh | sh
