Why setupkaro

Everything you need. Nothing you don't.

One Command

Run setupkaro init and get a complete project structure instantly. No manual configuration, no copy-pasting.

Production-Ready Defaults

ESLint, Prettier, TypeScript config, GitHub Actions CI, Dockerfile, docker-compose, Jest, README — all configured and working.

Multi-Language

TypeScript, React, Python, Go, Rust, Java, Node.js, and more. Each template follows idiomatic best practices for its ecosystem.

Secure by Default

No telemetry, no data collection, runs entirely offline. Your code never leaves your machine unless you choose to push it.

Team Templates

Share private templates across your organization. Enforce standards, reduce onboarding from days to minutes.

Extensible

Create custom templates with our simple JSON schema. Publish to the community marketplace or keep them private.

Installation

Install in seconds

npm / npx

Install globally or run directly with npx — no installation required.

# Run instantly (recommended)
npx setupkaro init my-app --template react-ts

# Or install globally
npm i -g setupkaro

Homebrew (macOS)

Install via Homebrew for easy updates and management.

brew tap setupkaro/brew
brew install setupkaro

Cargo (Rust)

Install the native Rust binary for maximum performance.

cargo install setupkaro

Binary Release

Download a standalone binary for Linux, macOS, or Windows — no runtime needed.

# Linux
curl -fsSL https://setupkaro.in/install.sh | sh

# Or download from GitHub Releases
