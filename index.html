features

Everything configured. Nothing assumed.

module:setup

Zero-config defaults

ESLint, Prettier, TypeScript, Jest, Husky, lint-staged — all pre-configured with sensible rules. npm run dev just works.

├── .eslintrc.json
├── .prettierrc
├── tsconfig.json
├── jest.config.js
└── .husky/pre-commit
module:ci

CI/CD included

GitHub Actions workflows for test, lint, typecheck, build, and Docker publish. Matrix testing across Node/Python/Go versions.

├── .github/workflows/test.yml
├── .github/workflows/lint.yml
├── .github/workflows/build.yml
└── .github/workflows/docker.yml
module:lang

Multi-language, idiomatic

Templates follow each ecosystem's conventions: pyproject.toml, go.mod, Cargo.toml, pom.xml — not lowest-common-denominator configs.

├── typescript/ (node)
├── python-fastapi/ (pip/poetry)
├── go-microservice/ (go modules)
├── rust-cli/ (cargo)
└── java-spring/ (maven)
module:telemetry

No telemetry. Ever.

Runs 100% offline. No analytics, no phone-home, no account required. Your projects, your machine, your business.

└── analytics: false
module:team

Team templates (soon)

Private template registry for your org. Enforce standards, cut onboarding from days to minutes. setupkaro init --team.

└── registry: private
module:ext

Extensible schema

Templates are JSON + file trees. Write your own, publish to the marketplace, or keep them private. setupkaro template create.

├── template.json (schema)
├── files/ (tree)
└── hooks/ (optional)

install

Four ways to start

npx (recommended)

Zero install. Always latest.

# Generate a React + TS project npx setupkaro init my-app --template react-ts # List all templates npx setupkaro list

Homebrew (macOS)

Native package management.

brew tap setupkaro/brew brew install setupkaro

Cargo (Rust binary)

Fastest startup. Single binary.

cargo install setupkaro

Standalone binary

Linux / macOS / Windows. No runtime.

# Linux / macOS curl -fsSL https://setupkaro.in/install.sh | sh # Or download from GitHub Releases https://github.com/iamRooney/progen/releases
