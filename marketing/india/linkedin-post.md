## Body

When I started building setupkaro, it was a personal tool — I wanted to stop rewriting the same ESLint config, GitHub Actions workflow, and Dockerfile for every new project.

What began as a weekend script became a proper CLI with 10 templates across TypeScript, React, Next.js, Python, Go, Rust, Java, Laravel, PHP, and Docker Compose.

### Why it matters for Indian developers:

- **Works offline after first run** (npm caches it) — great for unreliable connections
- **No account, no telemetry** — important for teams with data policies
- **Generates Docker + CI/CD out of the box** — standardizes deployment across teams
- **Extensible:** companies can fork and add internal templates without publishing to npm
- **MIT license** — free for commercial use

### The Kerala connection:

Built in Kochi, fueled by filter coffee and late-night debugging. The name "setupkaro" comes from Hindi/Urdu "karo" (करो) — "do it / make it happen." It's a small nod to the multilingual reality of Indian dev teams.

### Try it:

```bash
npx setupkaro init my-app --template react-ts
```
