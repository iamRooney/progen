## Verification Needed Before Posting

- [ ] Each community's self-promo policy (some allow only weekly threads)
- [ ] Language preference (English vs Malayalam)
- [ ] Whether they allow GitHub links directly or prefer case studies
- [ ] Contact admins for Kerala JS, Python Kerala, Go Kerala, Rust India, Laravel India
- [ ] KSUM submission process (check ksum.gov.in for current contacts)

## Suggested Posting Order

1. **Twitter/X thread** (immediate, your own audience)
2. **LinkedIn** (professional network, tag colleagues)
3. **Kerala JS** (local community, high engagement)
4. **React India / Laravel India / Go India / Rust India** (stack-specific)
5. **Python Kerala** (growing community)
6. **KSUM newsletter** (official recognition)
7. **Indie Hackers India** (founder audience)
8. **Hashnode India** (SEO backlink)
9. **Media tip lines** (after some traction)
