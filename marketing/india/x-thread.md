## Tweet 1/4

Made in Kerala, for the world 🇮🇳

setupkaro — zero-install CLI that generates production-ready projects in one command:

npx setupkaro init my-app --template react-ts

Templates: TypeScript, React, Next.js, FastAPI, Go, Rust, Java Spring, Laravel, PHP, Docker Compose

No install. No telemetry. MIT licensed.

## Tweet 3/4

Why "setupkaro"? 
"Karo" (करो) = "do it" in Hindi/Urdu.

Built in Kochi because I got tired of spending 45 mins configuring tooling before writing code. Now it's 30 seconds.
