## To Verify Before Submitting

- [ ] Check each list's CONTRIBUTING.md for exact format (alphabetical? category? emoji?)
- [ ] awesome-selfhosted: confirm they accept dev tools (some only want user-facing apps)
- [ ] awesome-nodejs: sindresorhus lists are strict — must be "awesome" quality, not just any package
- [ ] All: ensure repo has ≥50 stars or clear activity (some lists require minimum traction)

## Submission Process

1. Fork the awesome list repo
2. Add entry in alphabetical order in the appropriate category
3. Follow their exact formatting (some use `- [name](url) - description`, others use `* [name](url) — description`)
4. Submit PR with the title format above
5. Respond to maintainer feedback
